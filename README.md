# DS_Final_Project_SZM
This repository contains materials related to my final capstone project for DS 450: Senior Capstone. The project integrates knowledge from my majors in Data Science and Physics to demonstrate my computational skills in data-driven exploration, including exploratory data analysis, data visualization, statistical analysis, and machine learning.

This repository also contains a directory titled Project EDA which contains the relavent documents for an exploratory data analysis for the NASA Exoplanet Archive dataset. The following documents within this repository include: a copy of the Jupyter Notebook Python Script (Using Google Collab) titled "Initial_Exoplanet_Habitability_Prediction_EDA" with the revised version titled "New_Exoplanet_Habitability_Prediction_EDA", the exploratory data analysis report highlighting key findings and data preprocessing steps titled "DS_EDA_SZM", the original raw NASA Exoplanet Archive dataset titled "exoplanet_habitability_data" in excel format, the cleaned version of the dataset titled "filtered_2026_dataset_new_final", the further cleaned version of "filtered_2026_dataset_new_final2", and the cleaned version to be used for modeling "filtered_2026_dataset_new_final3", and a copy of the Habitable Worlds Catelog which contains the target variable needed for extraction. 

This repository also contains a directory titled Project Prelimary Predictive Analysis which contains the Jupyter Notebook Python Script (Using Google Collab) titled "DS_Preliminary_Models" which highlights the predictive models I used to predict Earth-Like Similarity.
